# 跨层 attention 复用的前提，在 GPT-2 上量出来是多少

日期：2026-11-13
脚本：`scanner/layer_reuse.py`；数据 `data/gpt2_k8_long.json`
状态：**初步测量**，单模型、两条长文本。结论方向明确，样本不足以定论。

## 1. 被检验的前提

两篇 2026 年的工作都建立在同一个观察上：

- **Multi-layer Indexer**（arXiv `2611.03768`）：相邻层选出的 token 几乎相同，因此后一层可以直接复用前一层的选择，省 decode 时间。
- **CLSA**（arXiv `2606.06467`）：跨层共享 KV 与路由索引，省 prefill 与存储。

两篇都是效率工作，都**没有报告这个前提的对照**：重叠是多少、相对什么高、是否高于"随便两个 attention 之间"的重叠。

## 2. 需要一个对照才说得清

如果只测「相邻层的 top-k 重叠 = 0.37」，这个数本身没有意义——它可能高、可能低、可能只是 attention 的普遍性质。三个对照：

| 对照 | 比较什么 | 排除什么解释 |
|---|---|---|
| 随机 k 子集 | 独立均匀抽样 | 纯粹由 k/seq 决定的基线 |
| 同层不同头 | 同一层，两个头，同一 query | 「头之间本来就各不相同」 |
| **同头移位 query** | 同一层同一头，query q 与 q+1 | 「attention 的全局位置偏好」← 决定性 |
| 剔除高频 key 后重算 | 去掉每层被选最多的 5 个位置 | 「重叠全部来自 BOS/标点/高频词」 |

## 3. GPT-2（12 层 × 12 头，2 条长文本，seq≈230，k=8）

| 量 | Jaccard |
|---|---|
| 随机 k 子集 | **0.0193** |
| 相邻层，同头 | **0.3698** |
| 同层，跨头 | **0.3745** |
| **同头，query 移位 1** | **0.4985** |

剔除每层最常被选的 5 个 key 之后：

| 量 | Jaccard |
|---|---|
| 相邻层，同头 | 0.3152 |
| 同层，跨头 | 0.3315 |
| 同头，query 移位 | 0.4485 |

### 3.1 跨模型复制

| 量 | GPT-2 (12层) | distilgpt2 (6层) |
|---|---|---|
| random k-subset | 0.0193 | 0.0193 |
| adjacent-layer, same head | 0.3698 | 0.3417 |
| same-layer, cross-head | 0.3745 | 0.3485 |
| same-head, shifted query | 0.4985 | 0.4816 |
| adjacent (common keys removed) | 0.3152 | 0.2904 |
| cross-head (common keys removed) | 0.3315 | 0.3096 |
| shifted (common keys removed) | 0.4485 | 0.4354 |

两个模型的层数、宽度、训练数据都不同，四个量的相对顺序完全一致：**同头移位 query 的重叠最高，跨层同头最低**（剔除高频 key 后也一样）。这不是单模型的偶然。

## 4. 读数

三条：

1. **相邻层的重叠确实远高于随机（0.37 vs 0.02）。** 前提不是空的。2. **但它不高过同层跨头（0.375），也不高过同头换一个 query（0.50）。** 后一个对照是关键：在同一个头里把 query 往后挪一位，top-8 的重叠比跨一层还高。
3. **剔除全局高频位置后，三者的相对顺序不变**（0.32 / 0.33 / 0.45）。所以这不是 BOS 与标点造成的假象。

**因此：「相邻层选同样的 token」是真的，但它是 attention 在自然文本上的普遍性质，不是层与层之间的特殊关系。** 用这个观察论证「跨层复用合理」，缺少的不是数据，是对照——而对照一做，量级就被同层现象吃掉了。

按层看，第 2→3 层的相邻重叠（0.558）明显高于其他，与它同层的跨头重叠（0.610）同步升高——再次是同层现象在主导。

## 5. 这条结论能走多远，现在不能走多远

**能说的**：在上述设置下，跨层选择的重叠不构成一个独立于同层现象的信号。
**不能说的**：

- 只有 GPT-2，dense attention。MLI 用的是 DeepSeek 的稀疏 indexer，选择机制不同（top-k over compressed KV），必须重测才能迁移结论。
- 只有 2 条长文本，`k=8`。重叠对 k 敏感，需要扫 k ∈ {4, 8, 16, 32}。
- 没有测**质量后果**。即使选择高度重叠，复用的代价仍可能很小或很大——重叠只是动机论据，不是效果证据。

## 6. 要成为一篇论文还差什么

1. **多模型**：distilgpt2、Qwen2.5-0.5B、Pythia 系列；有稀疏 indexer 的开源实现则直接测。
2. **k 扫描**：重叠对 k 的依赖决定结论的稳健区间。
3. **把动机与效果接上**：在能真正复用的模型上，测「复用后 loss/ppl 变化」对照「不复用的重叠度」，回答「重叠高是否意味着复用安全」。

第 3 点是这条线能否变成研究的分界线。前两点是必要的地基。

## 7. 复现

```bash
cd attn-reuse
python3 scanner/layer_reuse.py --selftest
python3 scanner/layer_reuse.py --model openai-community/gpt2 --k 8 --json data/gpt2_k8_long.json
```

`--selftest` 五项：Jaccard 恒等与半交、随机基线随 seq 单调下降、模型确实返回 12 层 attention、相邻重叠高于随机。第三项曾因 transformers 5.x 的模块路径变化失败（`model.h.attn` 不存在），第四项曾因短文本（seq≈15、k=8）而虚假成立——两者都已修，原因记在代码注释里。
