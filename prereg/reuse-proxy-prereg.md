# 预注册：post-hoc 跨层可替换性是否由功能性贡献决定

**状态**：判据先于数据。本文档写定时，`c_l`（下述量）**从未在真实模型上计算过**。

**已知污染声明**：在此之前我已看过 ① 单层复用的 Δloss 排序（`data/reuse_single.json`：
0→1 是 +0.574，其余 +0.032…+0.088）；② 索引重叠与 CKA 各自与 Δloss 的相关
（r = −0.055 / −0.341）。所以「哪个层代价大」这个信息我已有，任何事后挑出来的预测量
都可能被这个先验解释。判据因此比通常更严（阈值 r ≥ 0.75）。

---

## 1. 要判的问题

**跨层 attention 输出复用，在什么条件下安全？**

现有两种答案都不成立：

- MLI / CLSA：相邻层选同样 token ⇒ 可复用索引。**已证伪**（r = −0.055, n=10）。
- 直觉：表示越像越可替换。**已证伪**（CKA r = −0.341, n=10，方向对但无预测力）。

剩下的假设是**功能性**的：一层输出能否被上一层替换，取决于它在残差流里**承担多少
功能**，与它像不像上一层无关。

## 2. 假设的精确形式

对第 *l* 层（l = 1…11）：`h_l` 是 attention 模块的输出（已过 c_proj），`W_U` 是
unembedding，`Δloss_l` 是单层复用的交叉熵增量。

```
c_l = mean_t || W_U · h_l[t] ||_2
```

**H1**：`Δloss_l` 与 `c_l` 正相关（贡献大的层，被替换后损失大）。
**H0**：|r| < 0.55。

## 3. 为什么是它

| 量 | 测的是 | 与「像不像」的关系 |
|---|---|---|
| 索引重叠 | 选了哪些位置 | 本身就是相似度 |
| CKA | 输出向量像不像 | 本身就是相似度 |
| **c_l** | **输出对词表的直接作用量** | **无关**（只依赖 O_l、W_U） |
| model stitching | 可训练缝合能否恢复 | 无关，但要训练 |
| activation patching | 换掉后哪个行为坏 | 无关，但要多次前向 |

`c_l` 只要一次前向加一次矩阵乘。若成立，跨层复用就有了不用试错的判据；若不成立，
剩下的候选成本高一个数量级，这条线的性价比要重估。

## 4. 判据（先于数据）

**主判据（GPT-2，n = 11 个层对）**

| 结果 | 判定 |
|---|---|
| Pearson r ≥ **0.75** 且 Spearman ≥ 0.70 | **成立** |
| 0.55 ≤ r < 0.75 | **边界**：换「方向投影」再试**一次**，仍边界即否决 |
| r < 0.55 或符号为负 | **否决**，这条线停 |

阈值 0.75 而非 0.7，因已看过 Δloss 排序。n=11 时 r=0.75 对应 p ≈ 0.008。

**复现判据（distilgpt2，n = 5）**：n=5 要 r > 0.88 才显著，门槛过高，故只做**方向
一致性**——符号必须与 GPT-2 相同，Spearman > 0。方向反即否决。

**增量判据**：以 Δloss 为因变量、`(c_l, CKA)` 为自变量做二元回归，`c_l` 偏回归系数
须 p < 0.05 显著；且 `|corr(c_l, CKA)| < 0.8`，否则它只是 CKA 的另一种写法。

**负向控制（判据必须能红）**

1. 打乱 c_l 层序 1000 次，实际 r 须在零分布 99 分位外。（来源: 判据实现在 attn-reuse/scanner/analyze_contribution.py，置换次数写在 `PERMUTATIONS` 常量）
2. 用 c_l 去预测一个与复用无关的量（各层残差范数），r 须接近 0。
3. `|corr(c_l, 层号)| < 0.5`。否则「c_l 预测 Δloss」等价于「层号预测 Δloss」。

## 5. 数据与实现

- 模型：`openai-community--gpt2`（12 层）、`distilbert--distilgpt2`（6 层），本地 snapshot
- 文本：与 `proxy_cka.py` 同一段约 900 token（保证与已有 Δloss 可比）
- `Δloss_l`：`data/reuse_single.json`（`reuse_effect.py --all-single` 产出）
- 脚本：`scanner/proxy_contribution.py`，selftest 四项（c(0)=0、线性、置换不变、零分布
  中位数≈0），全部通过
- 输出：`data/contribution.json`

## 6. 三种结果各自意味着什么

**成立**：这条线有论文形态——两个否定 + 一个正向判据 + 一个可用预测量。下一步上真模型
（Qwen/Llama 级）与真实 indexer，验证跨架构成立，**那才需要 GPU**。

**边界**：只许换「方向投影」而非幅度再试一次；仍边界即按否决处理。不设第三次。

**否决**：这条线停。剩下候选（stitching / patching）成本高一个数量级，结论最多是
「某些层可替换」这种工程结论，进不了顶会。**这时应回到「哪条线值得做」重新选，
不是继续加实验。**

## 7. 这个预注册防什么

- 防事后挑好看的量报出来（判据写死，阈值因已看 Δloss 而上调）
- 防 n=11 的系数侥幸大（置换检验 + 层深混淆检查）
- 防新量其实是旧量的改写（增量判据 + 与 CKA 相关上限）
- 防方向反了还硬解释（方向不一致直接否决）

防不住的：小模型结论不能外推到 7B 以上。这一点在任何结果下都要写进 limitation。
